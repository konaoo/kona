# kona_tool/scripts 目录说明

`kona_tool/scripts/` 放的是后端专属脚本，不是仓库级脚本。

这里适合放：

- 定时任务入口
- 数据修复脚本
- 运维辅助脚本
- 后端专属的一次性迁移脚本
- 本地开发库初始化脚本

这里不适合放：

- 纯临时排障脚本
- 跑完就没价值的输出文件
- 和后端主工程无关的试验文件

判断标准很简单：

如果脚本只服务 `kona_tool`，就放这里。
如果脚本服务整个仓库，应该放到仓库级 `scripts/`。

当前新增：

- `setup_local_demo_data.py`
  用途：重建本地固定测试账号 `konae / qq111111`，并补本地联调常用样例数据。
  范围：只动本地开发库，不碰线上。

- `reconcile_recent_fund_navs.py`
  用途：定时任务按 T+1 回扫最近 2 天场外基金的确认净值；手动排查时可回扫最近 7 天，只补缺失或与确认净值不一致的逐资产收益明细。
  默认只检查缺失明细；带 `--apply` 才会写库，并在写入前生成 SQLite 一致性备份。`--verify-existing` 用于人工全面核验，不放进每天定时任务。场内基金、股票和当天数据不会处理。
