# kona_tool/static 目录说明

`kona_tool/static/` 放的是后端服务直接提供的静态资源。

这里应该放：

- 后台页面需要的静态文件
- 前端构建后确实要由后端直接托管的资源

这里不应该放：

- 临时截图
- 个人素材备份
- 和线上服务无关的试验文件

如果某份资源只是设计备份或素材原件，它更应该放在工作区顶层的 `UI素材/`，而不是这里。

## SPA 托管规则

后端通过 `web_entry_handlers.py` 托管 Web SPA 时，要区分两类请求：

- `/app/analysis` 这类页面路由：允许回退到 `index.html`
- `/assets/app.123.js` 这类静态资源：文件不存在必须返回 404，不能回退到 `index.html`

原因是发布后浏览器可能还会请求旧版本 JS/CSS chunk。如果这类缺失资源返回了 `index.html`，浏览器会把 HTML 当脚本或样式解析，用户侧表现通常就是白屏或资源解析错误。
