## 4. 已知高优先级问题（P0）

## 4.1 App 登录“网络连接异常”

现象：
- 手机端偶发/持续出现 `HandshakeException`、`connection reset by peer`

判断依据（已验证过）：
- 有时请求在 TLS 握手阶段就失败，业务登录接口日志没有落到后端。
- 不是账号密码错误，也不是数据库错误。

当前最稳策略：
1. 若用户大面积不可登录，立刻把域名 A 记录临时切回旧 AWS（`57.180.79.186`）。  
2. 保留腾讯云继续调试，等备案/入口链路稳定后再切回。

DNS 验证命令：

```bash
dig +short kakawallet.fun
dig +short www.kakawallet.fun
curl -vk --connect-timeout 8 https://kakawallet.fun/api/web/config
```
