# 接口与页面对照图

这份文档专门解决一个很实际的问题：

`某个页面出了问题，到底该去看哪个接口、哪个状态文件、哪个后端入口？`

这不是接口大全，而是“页面和接口的对照图”。

适合拿来排这些问题：

- 为什么这个页面数字不对
- 为什么这个页面刷新没生效
- 为什么 Web 和 App 看起来不一致
- 为什么后台某块加载不出来

---

## 10. 最实用的排查方式

以后你查问题，按这个顺序来最快：

### 页面显示不对

先看：

1. 是 Flutter 还是 Web
2. 这个页面吃的是 `store/AppState` 还是自己直接调接口
3. 页面对应接口是哪几个
4. 后端入口在 `app.py` 还是 `admin_routes.py`

### 数据不一致

先分清：

1. 是实时页还是历史页
2. 是价格问题还是快照问题
3. 是前端状态没刷新，还是后端返回值就不对

---

## 11. 一句结论

你可以把当前项目理解成：

- Flutter：`AppState -> 页面 -> 后端接口`
- Web：`shared/store -> 页面 -> 后端接口`
- 后台：`Admin 页面 -> admin_routes.py`

只要先把这条主线看明白，后面很多问题其实就不需要到处翻了。
